# checking-service

Сервис проверки контрагента по ИНН через API Checko.

Планируемый публичный адрес:

`https://checking.aikcu.ru`

## Что делает сервис

Пользователь вводит 10-значный ИНН юридического лица.

Сервис:

1. принимает ИНН на frontend;
2. отправляет запрос в собственный FastAPI backend;
3. backend обращается к API Checko;
4. получает сведения об организации;
5. возвращает frontend только нужные поля;
6. показывает основные данные и факторы риска.

Архитектура:

`браузер → FastAPI → Checko API`

API-ключ Checko не передаётся в браузер.

## Переменные окружения

Для локальной разработки используется:

`.env`

Обязательная переменная:

```text
CHECKO_API_KEY=
```

В неё вручную записывается API-ключ из личного кабинета Checko.

Пример безопасного файла:

`.env.example`

```text
CHECKO_API_KEY=
```

Настоящий ключ нельзя:

* публиковать;
* отправлять в Git;
* помещать в frontend;
* записывать в README или TZ;
* передавать пользователю через API.

---

## Факторы риска

Проверяются:

1. недостоверный юридический адрес;
2. массовый руководитель;
3. массовый учредитель;
4. дисквалифицированные лица в руководстве;
5. включение в реестр недобросовестных поставщиков;
6. признак нелегальной деятельности на финансовом рынке;
7. включение организации в санкционные списки;
8. санкции в отношении учредителей.

Frontend показывает все 8 проверок.

Если риск отсутствует:

`Не выявлено`

Если риск присутствует:

`Выявлено`

## Тестовый запрос к Checko

Для изолированной проверки интеграции используется:

`test_checko.py`

Запуск:

```powershell
.\.venv\Scripts\python.exe .\test_checko.py
```

Скрипт:

* читает ключ из `.env`;
* отправляет тестовый запрос в Checko;
* не выводит сам API-ключ;
* выводит только основные результаты запроса.

Важно: запуск теста расходует один запрос дневного лимита Checko.

---

## Лимит Checko

Используется бесплатный тариф `Лайт`.

Лимит:

**100 запросов в сутки.**

API возвращает служебное поле:

```text
meta.today_request_count
```

Оно используется локальным диагностическим скриптом для контроля количества запросов, но не возвращается публичным API приложения.
